HOW IT WORKS

THREE STEPS. NO SETUP.

  1. 01

    ADD YOUR CREW

    Type in everyone's name, in the order you're sitting. Nobody downloads anything.

  2. 02

    DEAL A CARD

    The phone shows whose turn it is. Read the card out loud and do what it says.

  3. 03

    RULES STICK

    Some cards set rules that last a few rounds. The game tracks them so you don't have to.
